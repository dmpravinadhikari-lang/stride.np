# Alev Kebab Sultanate — source pictures

Their own photographs, taken from alevkebab.com.np and resized for a
1080-wide render (the originals run to 2560px, which the renderer does not
need and the repository should not carry).

`logo.png` is the mark from the site header. The red `#7A1316` and the gold
`#D8A848` in `src/alev/brand.ts` are sampled from it by pixel count, not
matched by eye.

Nothing here was generated. If the restaurant reshoots, drop the new files in
under the same names and re-render — no code changes.
